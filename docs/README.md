## 기능 정리
- 사용자로부터 경주할 자동차의 이름을 입력받는 기능
	- 조건 :
        1. 자동차 이름은 쉼표(,)로 구분
        2. 이름은 5자 이하만 가능
    - 에러 : ```IllegalArgumentException``` 발생


- 사용자로부터 시도할 횟수를 입력받는 기능


- 각 자동차 별로 무작위 값 구하는 기능
    - 조건 : 0 ~ 9 사이의 숫자


- 각 자동차 별로 전진할지 여부 판단하는 기능
    - 조건 :
        1. 무작위 값이 4 이상일 경우 **전진**
        2. 무작위 값이 4 미만인 경우 **정지**


- 경주 실행 결과를 자동차 별로 출력하는 기능


- 최종 경주 우승자를 출력하는 기능
    - 조건 :
        1. 우승자는 한명 이상일 수 있음
        -> 우승자가 여러명일 경우 쉼표(,)로 구분
